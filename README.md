# Data Analytics Projects 

** ## House Price Prediction (Ames Housing) **
File: Machine Learning Project.ipynb

Predicting house SalePrice using Machine Learning in Python.

- Dataset: Ames Housing (Kaggle), 10 selected columns
- Steps: data cleaning, X/Y split, 80/20 train-test split, StandardScaler, Linear Regression
- Results: R2 = 0.74, MAE = about $25,300
- Tools: Python, Pandas, Scikit-learn, Jupyter Notebook
